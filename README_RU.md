# Strange Visuals

Визуальный клиентский мод для Minecraft Fabric 1.21.11.

## Требования
- **JDK 21+**
- **Fabric Loader 0.19.1+**

## Сборка

```bash
cd source

# Windows
.\gradlew.bat build

# Linux / macOS
./gradlew build
```

Собранный JAR-файл будет находиться в `source/build/libs/`.

## Управление
- `Right Shift` — меню ClickGUI
- `Insert` — переключение панорамы

## Конфигурация
Настройки сохраняются в `.minecraft/config/strangevisuals_config.json`.
